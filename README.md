# Infinity Law

Sistema de gestão para escritórios de advocacia (Next.js + Supabase). Escopo em `PRODUCT.md`.

## Início rápido

```bash
npm install
cp .env.example .env.local   # preencher valores; nunca versionar
npm run dev
```

Verificação: `npm run typecheck && npm run lint && npm test`. Detalhes em `docs/onboarding.md` e `docs/quality.md`.

## Mapa de documentos

- `AGENTS.md` / `CLAUDE.md`: instruções para agentes.
- `PRODUCT.md`: produto. `docs/architecture.md`: estrutura. `docs/design.md`: interface.
- `docs/onboarding.md`: preparação. `docs/quality.md`: checks. `docs/setup.md`: adoção do vibe-coding-toolkit e evidências.
